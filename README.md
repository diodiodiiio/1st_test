# Deutsch Lernen 🇩🇪

ドイツへのトレーニー渡航前に基礎ドイツ語を楽しく学ぶための React Native (Expo) アプリ。

## 特徴

- **6ユニット・段階解放**: 生活必需度順に設計されたカリキュラム
- **3ステップ学習**: フラッシュカード → クイズ → 会話シナリオ
- **XP & ストリーク**: 毎日続けたくなるゲーミフィケーション
- **5段階レベル**: Anfänger（初心者）からMeister（マイスター）まで
- **進捗保存**: アプリを閉じても学習記録が残る

## カリキュラム

| ユニット | テーマ | 内容 |
|:---:|---|---|
| 1 | 挨拶・自己紹介 | 基本の挨拶、自己紹介フレーズ |
| 2 | 数字・時間・日付 | 数字、時刻の読み方、曜日・月 |
| 3 | 日常フレーズ・道案内 | 助けを求める、道を聞く |
| 4 | 買い物・外食 | 値段の確認、注文、支払い |
| 5 | 交通・移動 | 電車・切符の買い方、乗り換え |
| 6 | 職場・ビジネス | 職場での基本コミュニケーション |

## セットアップ

```bash
npm install
npx expo start
```

iOS シミュレータ・Android エミュレータ、または [Expo Go](https://expo.dev/go) アプリで動作確認できます。

## 技術スタック

- **React Native** + **Expo SDK 52**
- **TypeScript**
- **React Navigation** (Bottom Tabs + Native Stack)
- **AsyncStorage** (進捗データの永続化)
- **Expo Haptics** (クイズの触覚フィードバック)
